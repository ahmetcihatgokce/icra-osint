# İcraOSINT
Yeni avukatlar için Türkçe icra takibi rehberi. Takip öncesi inceleme, takip yolu seçimi, dosyanın açılması, tebligat ve itiraz, tahsil ve haciz yöntemleri, satış, şikâyet riskleri ve kapanış adımlarını resmî kaynaklarla açıklar. Kaynak atlasında gerçek ve tüzel kişiler için kurumlar ve erişim şartları aranabilir. Uygulama dosya veya kişi bilgisi istemez.

[Canlı rehber](https://acgokce.vercel.app/icra-osint)

Node.js 24 ile `npm ci` ve `npm run dev`. Üretim için `npm run build`, tip kontrolü için `npm test`, tek HTML önizlemesi için `npm run portable`. GitHub Actions main değişikliklerini derleyerek preview dalında yayımlar. Kaynak bağlantılarını `npm run links` denetler. MIT lisansı.
